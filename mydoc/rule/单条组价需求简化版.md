# 单条组价功能需求 - 简化版

## 概述
在菜单上新增"单条组价"入口，支持用户为单条清单项逐条执行套定额。

---

## 功能流程

### 1. 菜单
- 在 Navbar 新增菜单项：「单条组价」→ `/pricing-task`

### 2. 任务列表页（`/pricing-task`）
- 显示已创建的组价任务列表
- 空态：「暂无任务，点击新增开始」
- 右上角：「新增组价任务」按钮

#### 新增任务弹窗
弹窗内有 3 个下拉字段（均必填）：
1. **工程**：选择 BoqProject（来自 `/api/boq/projects`）
2. **定额专业**：多选 bs2024_chapters（来自 `/api/bs2024-match/chapters`）
3. **对比工程**（可选）：选择 ManualBoqProject（来自 `/api/manual-boq/projects`）

点「创建并进入」→ 进入任务详情页

### 3. 任务详情页（`/pricing-task/[taskId]`）

#### 顶部信息栏
显示：工程名 + 定额库名 + 对比工程名（若有）

#### 左侧清单列表
- 显示所有清单项（code + name）
- 点击展开显示详情（描述、单位、工程量）
- 选中项高亮显示
- 选中后底部出现「套定额」按钮

#### 右侧占位区
纯占位显示（暂无逻辑）：
- 📝 提示词
- 🧠 推理过程
- ✓ 匹配结果

---

## 数据存储
- 任务数据存 localStorage（key: `pricing_tasks`）
- 每个任务包含：id、name、project_id、chapter_ids、manual_project_id 等

---

## 使用的现有 API
| API 端点 | 用途 |
|---|---|
| `GET /api/boq/projects` | 获取工程列表 |
| `GET /api/boq/all-items?project_id=X` | 获取清单项 |
| `GET /api/bs2024-match/chapters` | 获取定额专业 |
| `GET /api/manual-boq/projects` | 获取人工工程 |
