# 单条组价页面 - 完整框架设计

## 概述
新建"单条组价"功能，支持用户选择清单工程、定额专业、对比工程后逐条手动触发套定额。
本阶段只做框架：任务列表、创建弹窗、详情页（左侧清单列表 + 右侧占位），不含推理逻辑和提示词。


## 二、任务列表页（`web/app/pricing-task/page.tsx`）

### 页面布局
- **顶部**：标题「单条组价」+ 右上角「新增组价任务」按钮
- **主体**：任务卡片列表（空态时显示提示「暂无任务，点击新增开始」）
- **存储**：任务数据存 `localStorage`（key: `pricing_tasks`）

### 任务数据结构
```typescript
interface PricingTask {
  id: string              // nanoid 或 Date.now() 生成
  name: string            // 任务名称
  project_id: number      // BoqProject.id
  project_name: string
  chapter_ids: number[]   // bs2024 专业章节 ID 数组
  chapter_names: string[] // 专业名称数组
  manual_project_id: number | null
  manual_project_name: string | null
  created_at: string      // ISO 时间戳
}
```

### 任务卡片显示
每张卡片显示以下信息：
- 任务名称（黑体）
- 工程名称
- 定额库名（逗号分隔多个专业）
- 创建时间
- 右侧「进入」按钮（点击跳转 `/pricing-task/{id}`）

### 创建弹窗（Modal）
弹窗包含以下必填/可选字段：

| 字段 | 类型 | API | 说明 |
|---|---|---|---|
| 工程名称 | 必填，单选下拉 | `GET /api/boq/projects` | 返回 BoqProject[]，显示 project_name |
| 任务名称 | 必填，文本输入 | — | 用户自填，非空校验 |
| 定额专业 | 必填，多选 checkbox | `GET /api/bs2024-match/chapters` | 显示 chapter_name 和 subitem_count，至少选一个 |
| 对比工程 | 可选，单选下拉 | `GET /api/manual-boq/projects` | 可选「不对比」，返回 ManualBoqProject[] |

底部按钮：
- 「取消」— 关闭弹窗
- 「创建并进入」— 校验字段 → 创建任务对象 → 写 localStorage → 跳转 `/pricing-task/{taskId}`

## 三、任务详情页（`web/app/pricing-task/[tid]/page.tsx`）

### 顶部信息栏
固定高度，显示任务上下文信息：
```
工程：XX 项目   定额库：砌筑工程、混凝土工程   对比工程：XX（若无则不显示）
```
从 localStorage 读取对应任务数据。

### 左侧：清单列表面板（`w-72`，固定宽度，可滚动）

**数据加载**
- API：`GET /api/boq/all-items?project_id=N`
- 返回：BoqItem[]

**显示逻辑**
- 每条清单项显示两行：
  - 第一行：`item_code` （mono 字体）+ `item_name`
  - 点击展开显示详情：
    - `item_description`（项目特征）
    - `unit` （单位）
    - `quantity` （工程量）
- 选中项高亮：`border-l-2 border-blue-700 bg-blue-50`

**底部操作**
- 选中某条清单后，底部显示「套定额」按钮（灰色）
- 点击「套定额」：暂只 `console.log`（后续接推理逻辑）

### 右侧：占位区域

纯静态占位，无任何交互逻辑，显示：
```
┌─────────────────────────────────────┐
│  📝 提示词                           │
│  （提示词模板功能即将上线）            │
│                                     │
│  🧠 推理过程                         │
│  （选择清单后点击套定额开始）          │
│                                     │
│  ✓ 匹配结果                         │
│  （推理完成后展示）                  │
└─────────────────────────────────────┘
```

样式：灰色虚线边框，文字灰色，`text-center`，`flex items-center justify-center`。

## 四、API 端点清单

本阶段使用的现有 API（无需新增）：

| 端点 | 方法 | 数据结构 |
|---|---|---|
| `/api/boq/projects` | GET | 返回 BoqProject[] |
| `/api/boq/all-items` | GET | 参数 `project_id`，返回 BoqItem[] |
| `/api/bs2024-match/chapters` | GET | 返回 BS2024Chapter[]（含 subitem_count） |
| `/api/manual-boq/projects` | GET | 返回 ManualBoqProject[] |

## 六、本地存储策略

使用 `localStorage` 存储任务列表：
```typescript
// 初始化
const tasks = JSON.parse(localStorage.getItem('pricing_tasks') || '[]')

// 创建任务
localStorage.setItem('pricing_tasks', JSON.stringify([...tasks, newTask]))

// 读取单个任务
const task = tasks.find(t => t.id === taskId)
```
