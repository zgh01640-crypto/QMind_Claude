# 单条组价重构 — 新建独立后端路由和前端页面框架

## Context

用户对单条组价功能进行大规模重构：

- AI 对话工具和提示词**重新设计**，不复用 `bs2024_match.py` 任何逻辑
- 定额数据改为**工具筛选**方式：AI 调工具从数据库拿候选集，而不是全量塞进 prompt
- 核心数据来源：`tqdk_*`（国标清单管理）和 `tdek_*`（定额管理）两组表
- 结果**写库**（新建结果表）
- 旧文件 `bs2024_match.py` 保持不变
- 逐步实现：先建框架，AI 流程和工具细节按步骤填充

---

## 一、核心数据表（工具筛选的数据源）

| 表            | 关键字段                                               | 用途                  |
| ------------ | -------------------------------------------------- | ------------------- |
| `tqdk_tqdzm` | `qdkid`, `zmbh`(9位编码), `zmmc`, `dw`, `zjh`         | 国标清单子目              |
| `tqdk_tqdzy` | `qdkid`, `qdzmid`, `dekid`, `dezmid`               | **清单→定额候选映射**（筛选入口） |
| `tdek_tdezm` | `dekid`, `id`, `zmbh`, `zmmc`, `dw`, `gznr`, `zjh` | 定额子目（含工作内容）         |
| `tdek_tzmgc` | `dekid`, `dezmid`, `lx`, `zmmc`, `dw`, `gcl`       | 工料机消耗量明细            |
| `tdek_tznhs` | `dekid`, `dezmid`, `tsxx`, `hssm`                  | 换算说明                |
| `tlibs`      | `id`, `mc`                                         | 定额/清单库目录            |

**筛选逻辑**：BOQ 清单项 `item_code` 去末3位 → 查 `tqdk_tqdzm.zmbh` → 得 `qdzmid` → 查 `tqdk_tqdzy` → 得候选 `dezmid` 集合 → 从 `tdek_tdezm` 拿定额详情

## 二、结果存储表（新建）

```sql
CREATE TABLE IF NOT EXISTS pricing_task_results (
    id              SERIAL PRIMARY KEY,
    boq_item_id     INTEGER NOT NULL,          -- 关联 boq_items.id
    boq_project_id  INTEGER NOT NULL,          -- 关联 boq_projects.id
    dezmid          BIGINT NOT NULL,           -- 定额子目 ID (tdek_tdezm.id)
    dekid           BIGINT NOT NULL,           -- 定额库 ID
    subitem_code    VARCHAR(64),               -- 定额编号
    subitem_name    TEXT,                      -- 定额名称
    qty_factor      NUMERIC(20, 6) DEFAULT 1,  -- 工程量换算系数
    work_procedure  TEXT,                      -- 对应工序描述
    confidence      VARCHAR(16),               -- high / medium / low
    missing_info    TEXT,                      -- 缺失信息说明
    ai_reasoning    TEXT,                      -- AI 推理摘要
    status          VARCHAR(16) DEFAULT 'pending', -- pending / confirmed / rejected
    created_at      TIMESTAMP DEFAULT NOW(),
    updated_at      TIMESTAMP DEFAULT NOW()
);
CREATE INDEX IF NOT EXISTS idx_ptr_boq_item ON pricing_task_results(boq_item_id);
```

DDL 放在 `api/routers/pricing_task.py` 的 `_ensure_schema()` 函数中，路由启动时执行。
